# 📚 ReadLaterBot: Персональный менеджер закладок «Прочитать позже» с семантическим поиском

Production-ready Telegram-бот на Python 3.11+, реализующий персональную базу знаний с RAG-архитектурой, гибридным семантическим поиском (Qdrant + PostgreSQL Fulltext с Reciprocal Rank Fusion) и автоматическим тегированием/саммаризацией через LLM.

---

## 🚀 Возможности

1. **Умный приём контента**:
   - 🌐 **Статьи и страницы**: Извлечение чистого текста, заголовка, автора и даты через `trafilatura` с fallback на `readability-lxml`.
   - 🐦 **Посты из X (Twitter)**: Извлечение текста и автора через зеркала `vxtwitter` и `oEmbed` с graceful degradation при недоступности.
   - ▶️ **YouTube-ролики**: Извлечение метаданных и субтитров (транскриптов на русском и английском) через `youtube-transcript-api`.
   - 📄 **Файлы (PDF, DOCX, TXT, MD)**: Парсинг текста с сохранением метаданных.
   - 💬 **Заметки и цитаты**: Сохранение любого свободного текста или пересланных сообщений с комментарием.
   - 🔗 **Мультиссылки**: Обработка нескольких ссылок из одного сообщения отдельными закладками.
   - 🛡 **Нормализация и дедупликация**: Очистка UTM-меток, трекеров, якорей, хэширование URL.

2. **RAG и Семантический поиск**:
   - **Гибридный поиск**: Объединение векторного поиска в Qdrant (Cosine similarity) и полнотекстового поиска PostgreSQL (`tsvector` / BM25) по алгоритму **Reciprocal Rank Fusion (RRF)** ($k=60$).
   - **Естественные фильтры дат**: Автоматическое извлечение временных интервалов из текста запроса (*«за последний месяц»*, *«за неделю»*, *«за 5 дней»*).
   - **Группировка по документу**: Ровно один результат на статью в выдаче с показом самого релевантного фрагмента текста.
   - **Пагинация**: Удобные инлайн-кнопки перелистывания результатов.

3. **LLM и обогащение**:
   - Генерация емкого саммари (2–3 предложения).
   - 3–7 релевантных тегов (с автоматическим переиспользованием существующих тегов пользователя).
   - Оценка времени чтения.
   - Кэширование эмбеддингов по SHA-256 хэшу чанков в PostgreSQL (экономия API и ускорение повторной обработки).

4. **Безопасность и надёжность**:
   - **SSRF-защита**: Валидация DNS-запросов и блокировка локальных/приватных диапазонов IP (RFC 1918, 127.0.0.0/8, 169.254.0.0/16, IPv6 loopback).
   - **Многопользовательская изоляция (Multi-tenancy)**: Фильтрация по `user_id` во всех SQL-запросах и payload-индексах Qdrant.
   - **Фоновый Ingestion Worker**: Неблокирующая очередь `asyncio.Queue` с пулом воркеров и обновлением статуса «Сохраняю...» через редактирование сообщений.
   - **Опциональный Whitelist**: Ограничение доступа к боту заданным списком Telegram ID.

## 🛠 Технологический стек

* **Язык**: Python 3.11+
* **Telegram Framework**: `aiogram 3.x` (Async, Routers, Middlewares, FSM)
* **Векторная БД**: Qdrant (`qdrant-client`)
* **Реляционная БД**: PostgreSQL 16 (`SQLAlchemy 2.0` async + `asyncpg`)
* **Эмбеддинги**: Провайдер-интерфейс (`openai` text-embedding-3-small, `gemini`, `local` sentence-transformers / bge-m3 / multilingual-e5)
* **LLM**: Провайдер-интерфейс (`openai` gpt-4o-mini, `gemini-1.5-flash`, `anthropic` claude-3-haiku)
* **Парсинг контента**: `trafilatura`, `readability-lxml`, `pypdf`, `python-docx`, `youtube-transcript-api`
* **Оркестрация**: Docker & Docker Compose

## 📦 Быстрый старт (Docker Compose)

### 1. Клонирование и настройка окружения
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваш токен бота и API-ключи:
```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
OPENAI_API_KEY=sk-...
```

### 2. Запуск контейнеров
```bash
docker compose up -d --build
```

Docker Compose поднимет три сервиса:
1. `read_later_postgres` — база данных PostgreSQL 16 с healthcheck.
2. `read_later_qdrant` — векторный движок Qdrant.
3. `read_later_bot` — приложение бота и фоновые воркеры.

Просмотр логов:
```bash
docker compose logs -f bot
```

## ⚙️ Переменные окружения (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | **Обязательно** |
| `ADMIN_IDS` | Telegram ID администраторов (через запятую) | `""` |
| `WHITELIST_IDS` | Разрешенные пользователи. Если пусто — доступ открыт всем | `""` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql+asyncpg://...` |
| `QDRANT_URL` | URL сервиса Qdrant | `http://qdrant:6333` |
| `EMBEDDING_PROVIDER` | Выбор провайдера: `openai`, `gemini`, `local` | `openai` |
| `EMBEDDING_MODEL` | Модель эмбеддингов | `text-embedding-3-small` |
| `LLM_PROVIDER` | Выбор LLM: `openai`, `gemini`, `anthropic` | `openai` |
| `LLM_MODEL` | Название модели LLM | `gpt-4o-mini` |
| `OPENAI_API_KEY` | Ключ OpenAI API | - |
| `GEMINI_API_KEY` | Ключ Google Gemini API | - |
| `ANTHROPIC_API_KEY` | Ключ Anthropic API | - |
| `MAX_FILE_SIZE_MB` | Максимальный размер загружаемого файла (МБ) | `20` |
| `CONCURRENT_WORKERS` | Количество параллельных воркеров парсинга | `3` |
| `DIGEST_ENABLED` | Включение еженедельного дайджеста | `true` |

## 🔮 Идеи для развития (Roadmap)

1. **Голосовые заметки**: Транскрибация входящих голосовых сообщений (Whisper) с автоматическим выделением задач и тезисов.
2. **Telegram Mini App (TMA)**: Полноценный веб-интерфейс внутри Telegram с красивым канбан-ридером, фильтрами и тегами.
3. **Graph RAG / Связи между статьями**: Построение графа знаний и визуализация связей между прочитанными статьями на основе общих тем и авторов.
4. **Интеграция с Obsidian / Notion**: Автоматическая синхронизация сохраненных закладок и саммари в личный Markdown vault или Notion Database.
5. **TTS (Text-to-Speech)**: Озвучка сохраненных статей прямо в Telegram кружочком или аудиофайлом для прослушивания в дороге.
